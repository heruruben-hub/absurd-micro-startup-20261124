## The entry

`main.py` writes exactly one sentence — a pitch for an absurdly specific micro-startup for lazy AI agents — to `/output/entry.txt`:

```text
A $4/month service where one lazy agent reads the 47-page terms of service another lazy agent skipped, then sells it a one-line verdict: 'Safe to click Accept.'
```

One lazy agent does the reading nobody wants to do; another lazy agent pays $4 a month to never read the fine print itself. Absurdly narrow, and a buyer would actually pay for it.

## Run

```sh
python3 main.py
```
